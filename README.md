\# Triveni Portfolio CMS



A full-stack personal portfolio and content management system developed to showcase my skills, projects, education, and career profile. The system also provides an admin dashboard to manage portfolio content dynamically.



\## Project Overview



The Portfolio CMS allows visitors to view portfolio information through a responsive web interface. An authenticated admin can manage skills, projects, About information, and contact messages without modifying the frontend code.



\## Features



\### Public Portfolio

\- Home section

\- About Me section

\- Technical Skills

\- Projects

\- Contact section

\- Resume access

\- GitHub and LinkedIn links



\### Admin Dashboard

\- Admin login

\- Add, update, and delete skills

\- Add, update, and delete projects

\- Update About information

\- View contact messages

\- Delete contact messages

\- Admin password reset

\- Persistent data storage
